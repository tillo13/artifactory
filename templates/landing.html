What the shared backend exposes

GET    /api/v1/users/me                     # { id, name, role }
GET    /api/v1/users                        # everyone on the crew
GET    /api/v1/tasks?column=&assigned_role=
POST   /api/v1/tasks                        # create
PATCH  /api/v1/tasks/<id>                    # update any subset
DELETE /api/v1/tasks/<id>
GET    /api/v1/comments?task_id=
POST   /api/v1/comments                     # author = current user
GET    /api/v1/materials?task_id=
POST   /api/v1/materials
PATCH  /api/v1/materials/<id>

Full spec: /openapi.json. Every submitted frontend rides this contract.
